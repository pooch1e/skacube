## S2.2 Ingest script

As a developer, I can turn the FITS cube into processed files with `uv run data/ingest.py <fits>`.

Acceptance:
- Inline (PEP 723) dependencies: `astropy`, `numpy`; nothing is added to `api/`
- Memory-maps the cube; checks 3 axes with `FREQ` third, and fails with a clear message otherwise
- Averages down to 256³ (not strided). 936 channels do not divide evenly into 256, so frequency uses fractional-overlap weights
- Averages raw kelvin first, then applies a symmetric asinh stretch around 0 K; 0 K maps to exactly byte 128
- Writes `volume.u8` (x, i.e. RA, fastest; Dec flipped as FITS row 1 is the bottom), gzip-compressed, plus `metadata.json`
- Prints the raw file's SHA-256 (compared with the [recorded value](../docs/background/dataset.md#source)), output sizes and time taken

`metadata.json` holds: header cards, per-axis values (RA/Dec centre and step, frequency start and step), redshift at both ends, source and output shapes, stretch limit and softening scale, raw checksum, volume checksum.

Tasks:
- [ ] T2.2.1 Read, validate, and the resampler (channel blocks, fractional overlap on frequency) — M
- [ ] T2.2.2 Symmetric clip, asinh stretch, quantise to uint8 — S
- [ ] T2.2.3 Writers and checksum/size report — S
- [ ] T2.2.4 Pytest file: averaging against known weights, 0 K → 128, byte order and orientation — S
